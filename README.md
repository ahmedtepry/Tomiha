# الناصية (Nasya)

عربية قهوة متنقلة: العميل يطلب من التطبيق وهو في الطريق، ويستلم قهوته جاهزة.

## الأجزاء

| الجزء | الحالة |
| --- | --- |
| قاعدة البيانات (Supabase) | المخطط الأول جاهز في `supabase/migrations/0001_init.sql` |
| تطبيق العميل (Android) | مخطط له، Flutter |
| برنامج الكاشير (Windows) | مخطط له، Flutter Desktop |
| لوحة المتابعة (ويب) | مخطط لها |

## قاعدة البيانات

- `drinks` و`drink_prices`: المشروبات وأسعار الأحجام (صغير، وسط، كبير).
- `addons`: البسكويت والشوكولاتة والسندوتشات.
- `orders` و`order_items` و`order_item_addons`: الطلبات (من التطبيق أو الكاشير).
- `shifts`: الورديات وجرد الكاش.
- `profiles`: الأدوار (`customer` و`cashier` و`manager`).

كل الجداول عليها RLS: المنيو للقراءة العامة، والطلبات يشوفها صاحبها والموظفين، وتعديل المنيو والورديات للموظفين فقط. جدول `orders` في Realtime عشان الكاشير يستلم الطلب فورًا.

أسعار المنيو في المخطط تقديرية، وبتتعدل من لوحة المتابعة.

## ملاحظات

- لا ترفع مفاتيح `service_role` ولا ملفات `.env` للريبو.
- الأرقام المالية والتكلفة في `docs/nasya_menu.xlsx`.
